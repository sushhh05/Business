# Archive — Legacy Prototypes

This directory contains legacy standalone single-file HTML versions of the Biroba Billing System created during the initial prototyping phase before the transition to the modern React 19 + Vite PWA architecture:

1. **`biroba_billing_v2.html`**: Secondary standalone prototype with inline styling and canvas rendering.
2. **`biroba_v1_backup.html`**: Initial standalone prototype backup.
3. **`biroba_vegetable_suppliers_daily_billing_record_system.html`**: Comprehensive standalone HTML billing system with embedded Google Apps Script sync helpers.

> **Note**: The production application runs entirely on the modern React 19 + Vite architecture in `/src`. These files are preserved purely for historical reference and backup purposes.
